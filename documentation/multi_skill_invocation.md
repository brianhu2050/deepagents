# 高级功能：多技能协同调用流程

在 `deepagents` 框架中，Agent 的强大之处不仅在于能使用工具，更在于它能够理解复杂的用户意图，并将其分解为一系列需要多个技能（Skills）协同完成的步骤。Agent 具备规划能力，可以决定是按顺序串行执行技能，还是在可能的情况下并行执行以提高效率。

## 流程图：从复杂需求到最终交付

下面的流程图详细展示了当用户提出一个需要多个步骤才能完成的复杂需求时，Agent 是如何思考、规划并协同调用多个技能来完成任务的。

![Multi-Skill Invocation Flow](./04_advanced_features/deepagents-cli-skill-flow.svg)

### 流程详解

1.  **接收复杂需求 (Complex User Request)**
    *   **用户输入**: 用户提出的不是一个简单的、单一动作的指令（如“读取文件”），而是一个高层次的目标（如“分析代码库的性能瓶颈并生成优化报告”）。
    *   **意图理解**: Agent 的核心 LLM 首先需要准确理解这个复杂需求背后的多个隐含步骤和最终目标。

2.  **思考与规划 (Thought and Planning)**
    *   **任务分解 (Task Decomposition)**: 这是最关键的一步。Agent 在其“思考”（Thought）过程中，会将宏观目标分解为一系列具体的、可执行的子任务。
    *   **技能匹配 (Skill Matching)**: 对于每一个子任务，Agent 会从其可用技能列表（由 `SkillsMiddleware` 提供）中寻找最匹配的技能。例如，“分析代码库”对应 `code_analysis` 技能，“找出性能瓶颈”对应 `performance_profiling` 技能。
    *   **执行规划 (Execution Planning)**: Agent 会根据子任务之间的逻辑依赖关系来制定执行计划。
        *   **串行执行**: 如果任务之间存在严格的先后顺序（例如，必须先分析代码才能找到性能瓶颈），Agent 会计划按顺序调用技能。
        *   **并行执行**: 如果多个任务之间没有依赖关系（例如，“检查代码风格”和“统计代码行数”），一个高级的 Agent M ay 决定一次性发起多个 `tool_calls`，让这些技能并行执行，从而大幅缩短总耗时。

3.  **发起工具调用 (Tool Calls)**
    *   **生成调用请求**: 根据规划，Agent 会生成一个或多个 `tool_calls`。在 `deepagents` 框架中，每个技能都被封装成一个可供 LLM 调用的工具。
    *   **并行可能性**: LangChain 和 `deepagents` 的架构原生支持在一个 `AIMessage` 中包含多个 `tool_calls`，这为并行执行创造了条件。

4.  **技能执行与结果返回 (Skill Execution & Result Return)**
    *   **工具分发**: `deepagents` 运行时会解析 `tool_calls`，并将每个调用分发给对应的技能（工具）去执行。
    *   **独立执行**: 每个技能在其上下文中独立运行，并返回其执行结果（成功、失败、输出数据等）。这些结果被包装成 `ToolMessage`。

5.  **综合结果 (Synthesize Results)**
    *   **信息汇总**: Agent 接收所有 `ToolMessage`，汇总所有技能的执行结果。
    *   **再次思考**: Agent 会再次进入“思考”阶段，评估已有的信息是否足以满足用户的最终需求。
    *   **决策**:
        *   如果信息充足，Agent 会开始进行最后一步的整合工作（例如，根据分析数据和性能数据撰写最终报告）。
        *   如果信息不足或某个技能执行失败，Agent 可能会重新规划，例如：尝试调用另一个备用技能，或者向用户请求更多信息。

6.  **最终输出 (Final Output)**
    *   **生成最终答案**: 在所有步骤成功完成后，Agent 会生成一个最终的、面向用户的响应。
    *   **交付产物**: 这个响应可能是对分析结果的总结，也可能是一个指向最终产物（如生成的报告文件）的链接或引导。

这个流程充分展示了 `deepagents` 作为一个智能的“问题解决者”而不仅仅是“工具执行者”的设计哲学。通过赋予 Agent 规划和协同调用多种技能的能力，它能够自主地完成更加复杂和有价值的任务。

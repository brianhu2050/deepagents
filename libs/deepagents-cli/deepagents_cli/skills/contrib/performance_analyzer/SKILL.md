# Performance Analyzer Skill

This skill guides the agent through a comprehensive performance analysis workflow. It leverages the filesystem to manage large datasets and orchestrates a sub-agent to generate custom analysis code.

## Workflow

1.  **Query Performance Metrics:**
    *   Call the `query_metric` tool with the `instance_id`.
    *   The tool will save a large JSON dataset to a file in the `/workspace/` directory and return the exact file path.

2.  **Generate Plotting Script:**
    *   Invoke the `code-generator` sub-agent using the `task` tool.
    *   Provide the following instructions to the sub-agent:
        *   "Read the performance data from the JSON file at the path returned by `query_metric`."
        *   "Write a Python script using `matplotlib` to plot the `cpu_usage` and `memory_usage` over time."
        *   "Save the generated plot as `/workspace/performance_chart.png`."

3.  **Save the Generated Script:**
    *   Take the Python code generated by the sub-agent.
    *   Use the `write_file` tool to save the script to `/workspace/plotter.py`.

4.  **Execute the Script:**
    *   Use the `execute` tool to run the script in the sandbox: `python /workspace/plotter.py`.
    *   This will generate the `performance_chart.png` file.

5.  **Verify the Output:**
    *   Use the `ls /workspace/` tool to confirm that `performance_chart.png` was created successfully.

6.  **Generate the Final Report:**
    *   Use the `write_file` tool to create a final report at `/workspace/performance_report.md`.
    *   Summarize the steps taken and confirm that the chart was generated.
